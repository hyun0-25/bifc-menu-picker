# 식당 목록 작성 기준 (PLAN 작업 3)

> `data/restaurants.json` 27곳을 어떻게 모았고 값을 어떻게 정했는지 적은 기록이다. 조사일: 2026-11-03

## 1. 출처와 선정 과정

- **출처**: 카카오맵 장소 상세 페이지. 가게마다 `source`에 주소를 남겼다. (예: https://place.map.kakao.com/27485313)
- **과정**
  1. "문현동 한식·중식·일식·양식·고기·분식·쌀국수·돈까스", "BIFC 맛집"으로 검색 → 129곳
  2. BIFC에서 도보 15분 이내 → 56곳
  3. 메뉴 가격이 공개된 곳 → 39곳 (가격을 모르는 가게는 예산 조건으로 거를 수 없어 제외)
  4. 카페·술집(안주 위주)·100g 단위 판매 가게를 빼고, 메뉴 종류가 고르게 섞이도록 **27곳** 선정
- 모든 가게는 조사일 기준 카카오맵에서 영업 중으로 표시되었다.

## 2. 항목별 값 정하는 기준

| 항목 | 기준 |
|---|---|
| `pricePerPerson` | 카카오맵 메뉴판의 앞 8개 가격의 **중간값**을 500원 단위로 반올림. 뷔페는 평일 성인 점심 가격(더스타뷔페 39,000원), 애슐리퀸즈는 평일 성인 런치 가격(19,900원) |
| `walkMinutes` | BIFC몰(문현금융로 40) 위치를 기준점으로 한 직선거리 × 1.3(길이 굽는 정도) ÷ 분당 67m(시속 약 4km), 올림. 최소 1분 |
| `cuisine` | 카카오맵 분류를 8가지로 옮김: 돈까스·우동·라멘·아부라소바 → 일식 / 삼계탕·국밥·막국수·기사식당 → 한식 / 닭갈비 → 고기 / 이탈리안·햄버거 → 양식 / 태국음식 → 아시안 / 뷔페·패밀리레스토랑 → 기타 |
| `groupSeating` | 카카오맵 "좌석 옵션"에 **단체석**이 표시된 가게만 `true` |
| `hasRoom` | "프라이빗룸"이 표시된 가게만 `true`. 표시가 없으면 **없다고 단정하지 않고** `"정보 없음"` |
| `reservation` | 카카오 예약을 받는 가게만 `"가능"`. 그 외는 `"정보 없음"` (불가로 확인된 가게 없음) |
| `maxCapacity`, `roomCapacity` | 카카오맵에 공개된 가게가 없어 모두 `"정보 없음"` |

## 3. 알려진 한계

| 항목 | 현황 |
|---|---|
| 단체석 표시 | 27곳 중 9곳 |
| 룸 확인 | 2곳 (성해루, 더스타뷔페) |
| 예약 가능 확인 | 2곳 (미도방 BIFC몰 본점, 하루키) — 둘 다 단체석 표시는 없음 |
| 최대 인원·룸 인원 | 0곳 |

그래서 **5명 이상 회식**은 단체석 표시가 있는 9곳 안에서만 추천되고, **룸이나 예약이 필요한 회식**은 후보가 거의 없다 (docs/test-results.md의 6·7·8·10번 질문이 0곳).

## 4. 값을 채우는 방법 (작성자)

가게에 전화하거나 방문해서 확인한 값만 파일에 고쳐 적는다. 확인 못 한 값은 짐작하지 않고 `"정보 없음"`으로 둔다.

우선 확인하면 효과가 큰 가게:

1. 단체석 표시가 있는 9곳(마루카츠, 주왕산삼계탕, 성해루, 루암밋타이, 작은딸, 봉평메밀막국수, 마산식당, 파스타빌라, 더스타뷔페): 최대 인원, 룸 유무·룸 인원, 예약 가능 여부
2. 회식용으로 좋아 보이는 가게: 룸 유무와 예약 가능 여부

고친 뒤에는 `npm test`로 형식을 확인하고, `EVAL_DATA=real npm run eval`로 다시 점검한다.
